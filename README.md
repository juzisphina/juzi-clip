# 橘子存片 JuziClip 🍊

把 X 和 Threads 貼文裡的影片存下來的小工具（Mac / Windows）。

**介紹頁：https://juzisphina.github.io/juzi-clip/**

- **一則貼文有好幾個影片**：每個影片都列出來，有預覽、長度和畫質，自己選要哪幾個。
- **影片不是這則貼文自己的**：會標出來源——「本篇」、「引用貼文 @某某」或「卡片 / 廣告」，預設只選本篇自己的影片。
- **預設最高畫質**，存成一般的 mp4，有畫面也有聲音。
- **代理自己加**：能直接連上 X 和 Threads 就不用設定。需要時，在「設定 → 網路」加上代理軟體（Clash、V2Ray、Shadowsocks 等）的連接埠，HTTP 和 SOCKS5 都可以；打開「代理」後，一條連不上會自動換下一條，最後再試直接連線。
- **繁體 / 简体**：預設繁體中文，左下角一鍵切換简体。
- **不留紀錄**：沒有帳號、沒有歷史紀錄，不上傳任何東西。

## 下載與安裝（Mac，Apple 晶片 M1–M4）

1. 下載 [JuziClip-macOS-arm64.dmg](https://github.com/juzisphina/juzi-clip/releases/latest/download/JuziClip-macOS-arm64.dmg)。
2. 打開 dmg，把 JuziClip 拖到旁邊的 Applications（應用程式）資料夾。
3. **第一次打開**：Mac 會提示「無法驗證開發者」（這個軟體沒有付費向 Apple 簽名）。按「完成」，再到 **系統設定 → 隱私權與安全性**，往下找到 JuziClip，按 **「強制打開」**。
   - 如果提示「已損毀」，打開「終端機」執行下面這行後再打開：
     ```
     xattr -cr /Applications/JuziClip.app
     ```

## 下載與安裝（Windows 10 / 11）

1. 下載 [JuziClip-Windows.exe](https://github.com/juzisphina/juzi-clip/releases/latest/download/JuziClip-Windows.exe)。瀏覽器提示「不常下載」時，按「…」→「保留」。
2. 不用安裝，這一個檔案就是整個程式，放在桌面就好。
3. **第一次打開**：如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。第一次會等 10 秒左右（Windows 在檢查新程式），之後大約 2 秒。

## 使用

1. 在 X 或 Threads 的貼文按「分享」→「複製連結」。
2. 打開橘子存片，按「貼上連結」，會自動尋找。
3. 選好影片和畫質，按「下載」。影片會存到「下載」資料夾。

## 下載不了？

| 狀況 | 怎麼辦 |
|---|---|
| 連不上 | 到「設定 → 網路」按「新增代理」，填代理軟體的連接埠（例如 `127.0.0.1:7890`），看測試結果是不是 ✓，再打開「代理」。都不行的話，把代理軟體切到「全域」模式試試。 |
| 尋找要多等幾秒 | 有些 Threads 影片（例如從 Instagram 分享過來的）要像瀏覽器一樣打開貼文才讀得到，大約 3–5 秒，正常。 |
| 沒有能下載的影片 | 貼文只有圖片，或是直播、YouTube 等外部連結影片。 |
| 還是不行 | 按錯誤下面的「複製錯誤訊息」，把內容傳給幫你的人。 |
